# Health Dashboard v0.1.0-beta

**First public beta release!** 🚀

An open-source platform democratizing access to intelligent medical laboratory exam analysis through AI-powered interpretation, correlations, and personalized recommendations.

## ✨ Highlights

- **AI-Powered Analysis**: Natural language medical interpretations
- **Multi-Exam Correlation**: Integrated analysis of related exams
- **Personalized Recommendations**: Diet, exercise, and monitoring plans
- **Historical Tracking**: Complete exam history from 2022-2026
- **Health Projections**: 24-month forecasts with multiple scenarios
- **Demo Mode**: Try it instantly with fictional patient data

## 🚀 Quick Start

```bash
git clone https://github.com/dsantosme/health_dashboard.git
cd health_dashboard
pnpm install
pnpm db:push
pnpm seed:demo
pnpm dev
```

**Demo Account**: health.demo@manus.im

## ⚠️ Important

This is **beta software** under active development. Do not use as the sole source of medical information. Always consult qualified healthcare professionals.
